📢 Notices Editor

Edit notices below, then copy the generated code into your index.html on GitHub.
1. Tap Copy Code above
2. Go to your repo → open index.html → tap the pencil ✏️ (Edit)
3. Find the block that starts with const NOTICES = { and ends with the matching };
4. Select and delete that whole block, then paste the copied code in its place
5. Scroll down → Commit changes
6. Wait ~1 minute for Vercel to redeploy — then it's live
